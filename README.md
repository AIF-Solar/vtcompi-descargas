# VTCompi — descargas

Aquí sólo están los **paquetes** de VTCompi, tu asistente VTC, para que el
programa pueda buscar e instalar sus versiones nuevas. El código no está en
este repositorio.

Cada versión está en [Releases](../../releases):

| Paquete | Para |
|---|---|
| `VTCompi-Windows.zip` | Windows 10/11: el programa |
| `VTCompi-mantenimiento-Windows.zip` | Windows: copias, restauración y credenciales |
| `VTCompi-macOS-AppleSilicon.zip` | Mac con chip Apple (M1, M2…) |
| `VTCompi-X.Y.Z-macOS-intel.zip` | Mac con Intel |
| `VTCompi-mantenimiento-…` | El mantenimiento de cada sistema |
| `sha256.txt` | La huella de cada paquete, para comprobarlo |

Hace falta una licencia para usarlo.
